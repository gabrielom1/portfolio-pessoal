# Portfolio Pessoal

## Descrição do Projeto
Este projeto é uma página web pessoal desenvolvida como parte da avaliação **VA1 - Verificação de Aprendizagem** da disciplina de **Gestão do Conhecimento**. 

A página apresenta meu perfil profissional, meus interesses, objetivos e uma lista das habilidades e tecnologias que domino e pretendo aprender.

## Objetivo
Desenvolver uma página estática simples, aplicando os conceitos de marcação e estilização, e utilizar o Git para o controle de versão com histórico incremental de desenvolvimento publicado no GitHub.

## Tecnologias Utilizadas
- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização da página.
- **Git**: Versionamento de código.
- **GitHub**: Hospedagem e compartilhamento do repositório.
